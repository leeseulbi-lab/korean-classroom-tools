한국어 수업 도구 · Korean Classroom Tools

한국어 선생님이 교실에서 바로 쓸 수 있는 작은 웹 도구입니다. 설치나 가입 없이 열어서 쓰세요.
Small, free web tools for Korean language classrooms. No sign-up, no installation.

짝 정하기 · Pair Maker 교사용

출석한 학생만 골라 2·3·4명씩 섞습니다. 이미 짝을 했던 학생끼리는 다시 만나지 않게 피합니다.
Random pairs and groups that avoid repeating past partners.

한글 퀴즈 · Hangul Quiz 학생용

모음, 자음, 받침, 소리 변화를 듣고 고르거나 소리 내어 읽습니다. 음원이 들어 있어 인터넷 없이도 됩니다.
Listen-and-choose and read-aloud practice for vowels, consonants and batchim. Works offline.

활용 연습 · Conjugation Quiz 학생용

-아/어요, -았/었어요, -(으)세요 등 문법 형태를 골라 동사·형용사 활용을 연습합니다.
Practise conjugating verbs and adjectives with the grammar forms you choose.

우리 반에 맞게 바꾸기 · Make it yours

짝 정하기는 화면의 "명단 편집"에서 학생 이름을 넣으면 됩니다. 활용 연습 문제는 conjugation-quiz/data.js 파일 하나만 고치면 바뀝니다. 자세한 방법은 GitHub 저장소의 안내(README)를 보세요.
Add your students in Pair Maker with "명단 편집". Change the conjugation questions by editing conjugation-quiz/data.js. See the README on GitHub for details.
